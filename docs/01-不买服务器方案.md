# 一、要不要买公网服务器？——不用

## 结论先说

**你这个需求（展示 + 下单登记 + 我看后台），一分钱服务器都不用买，也不用买域名、不用备案域名、不用配 HTTPS。**
用微信自家的 **云开发（CloudBase）** 就够了：数据库、图片存储、后端代码（云函数）全在微信云里，只有你的小程序能调，不需要对外暴露任何服务器。

## 它是怎么跑起来的

```
微信用户
   │  打开小程序
   ▼
小程序前端（WXML/JS，跑在用户手机微信里）
   │  wx.cloud.callFunction('shopapi', {action:'createOrder'})
   ▼
云函数 shopapi（跑在微信云里，Node.js）
   │  读写
   ▼
云数据库 products / orders / settings    云存储 商品图片
```

三个角色：

| 传统做法 | 云开发做法 | 你要做什么 |
| --- | --- | --- |
| 买一台云服务器（ECS/轻量） | 不用买 | 什么都不用买 |
| 装 Node/Java、配 Nginx、开端口 | 云函数，上传即运行 | 右键「上传并部署」 |
| 装 MySQL | 云数据库（文档型，自带增删改查） | 控制台点点鼠标看数据 |
| 对象存储 + CDN 存图片 | 云存储（自带 CDN） | 小程序里选图上传 |
| 域名 + HTTPS 证书 + 域名备案 | 不需要域名 | 无 |
| 自己做登录鉴权（token/session） | 云函数里直接拿到用户 openid | 无 |

代码层面：云函数里一行 `cloud.getWXContext().OPENID` 就是当前用户的唯一身份，**伪造不了**，所以订单归属、管理员权限都是天然安全的，不用自己写登录。

## 钱的问题（重要，别踩坑）

- **开发阶段：0 元。** 每个小程序可以免费创建一个云环境，配额和付费的基础套餐一样。
- **⚠️ 坑在这：小程序一旦「发布上线」，免费环境会在上线后第 15 天到期**，之后要转成付费，否则环境被停、数据读写会失败。要长期用就早点转。
- 付费基础套餐：**19.9 元/月**（原价 39，长期 5 折），配额大致是：
  - 调用次数 20 万次/月（1 次数据库读写 = 1 次调用）
  - 容量 2 GB（数据库 + 存储合计）
  - CDN 流量 5 GB/月
  - 云函数资源 10 万 GBs
- 你这场景的量级：**20 个同事、一个月 100 单**，大概消耗几千次调用、几百 MB 流量 —— 免费额度的零头都用不到。所以真实成本就是 **19.9 元/月**。
- 价格可能调整，以云开发控制台「环境 → 套餐」页面为准。

## 对比一下其他方案，为什么不用它们

| 方案 | 成本 | 适合你吗 | 说明 |
| --- | --- | --- | --- |
| **微信云开发**（本项目用的） | 免费开发 / 上线后 ~19.9 元/月 | ✅ 最合适 | 零运维，数据在微信云，只有小程序能访问 |
| 微信云托管 | 按容器计费，通常 20 元+/月起 | ❌ 过度 | 适合已有 Docker 服务的项目 |
| 自建服务器 + 域名 | 轻量服务器 ~100 元/年 + 域名 50 元/年 + 证书（免费） | ❌ 自找麻烦 | 还要域名备案（个人备案 1-3 周）、配 HTTPS、防攻击、自己备份 |
| Serverless 函数（腾讯云/阿里云）+ 云数据库 | 免费额度可用 | 一般 | 要自己配 API 网关、跨域、鉴权，比云开发多绕一圈 |

**唯一需要用钱的地方**，是你如果想在微信里做「在线支付」：那需要企业/个体户主体开通微信支付商户号（有费率、有资质要求）。**而你这个流程不需要**——线下确认邮费、微信转账收款，反而更简单，也不用担心资金结算和退款纠纷。

## 数据在哪 / 会不会被锁死

- 云开发控制台 → 数据库 → 选中集合 → 右上角「导出」，可以导出 JSON/CSV。
- 图片在「云存储」，可以整目录下载。
- 所以数据是你的，随时能搬走。真要哪天迁移到自己的服务器，orders/products 两个集合导出就是完整数据。

## 这个方案的边界（说清楚，免得后面踩坑）

1. **不支持在线支付**：不是你不想做，是个人主体做不了。如果你后面想开微信支付，需要个体户/企业主体 + 商户号。
2. **不主动推送消息**：用户下单后，你手机上不会自动响。当前设计是「你主动打开后台看」。想要「有新订单通知我」，需要「订阅消息」（用户下单时点一下授权，之后才能推给你），这是下一步可以加的（免费，但模板要申请）。
3. **数据库是文档型**，不是 MySQL。做这种小工具完全够，复杂报表会难受。
4. **管理员身份靠 openid 白名单**：你换微信登录，就看到后台了（因为 openid 变了）。解决办法在 `docs/02` 里写了。
