# 四、怎么测试

**不用等朋友部署服务器，也不用等审核，今天就能开测。** 下面按"从便宜到真实"排好，走到第 2 层就够你判断这套东西能不能用了。

---

## 0. 最快开测：10 分钟走通一遍

四条路，选一条。**想最快看到东西走路线 0（浏览器网页版）**，想测真小程序走路线 A/B。

### 路线 0：浏览器网页版（最省事，不用微信）

`server/public/` 里带了一个网页版（`app.html`），和小程序共用同一套后端，界面是照着小程序重画的。**不用装开发者工具、不用 AppID、不开微信**，浏览器里就能把整条流程点完，顶栏还能一键切换"我是谁"。

**第一步：启动服务器**（二选一）

- **双击项目根目录的 `启动服务器.command`** —— 会自动起服务并打开浏览器。第一次双击若提示"无法验证开发者"，右键 → 打开。
- 或者手动：`cd techan-shop/server && DEV_MODE=1 node index.js`（这个终端窗口要一直开着，Ctrl+C 就是关服务器）

**第二步：浏览器打开** <http://127.0.0.1:3000/app.html>

1. 点「初始化店铺数据」→ 店铺建好，首页是空的（正式版不写示例商品）。去「卖家工具 → 商品」新增 1~2 个，再回来往下测
2. 顶栏把「体验身份」切到「同事小王」→ 加两件 → 去登记 → 故意不填地址提交（会被拦）→ 填好提交
3. 切回「我（卖家）」→ 我的 → 进入卖家工具 → 看到姓名/电话/地址 → 报价运费 → 已收款 → 已发出
4. 再切回「同事小王」→ 登记页 → 状态和含运费的合计都变了

**打不开页面？按这个顺序查（90% 是第一种）**

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 浏览器提示"无法访问此网站 / 拒绝连接" | **服务器没在跑** | 双击 `启动服务器.command`；或终端里执行启动命令，看有没有红色报错 |
| 终端一启动就报 `EADDRINUSE` | 3000 端口被别的程序占了 | 关掉占用者，或换端口 `PORT=3001 node index.js`（地址相应改成 3001） |
| 终端报 `command not found: node` | 没装 Node.js | 装 LTS 版：<https://nodejs.org> |
| 页面能开但一直转圈、提示"连不上后端" | 后端被关了 / `DEV_MODE=1` 漏了 | 网页版靠 devOpenid 免登录，必须带 `DEV_MODE=1` |
| 只有手机打不开，电脑正常 | 手机连的是另一个网络 | 用电脑局域网 IP，见路线 C |

自动回归：`node scripts/web-e2e.js`（无头 Chrome 真点一遍，21 项断言，需本机装有 Chrome）。

> 网页版靠 `devOpenid` 免微信登录，所以服务器必须 `DEV_MODE=1` 启动；正式部署后这个页面还在，但没人能登进来（只能真微信登录后走小程序）。交付给朋友时可以把 `public/app.*` 三个文件删掉。

### 路线 A：微信开发者工具（测真小程序）

**① 起本地服务器**（新开一个终端窗口，别关，关了小程序就报网络错误）

```bash
cd techan-shop/server
DEV_MODE=1 node index.js
```

看到 `特产小铺后端已启动：http://0.0.0.0:3000` 就成了。顺手验证一下：浏览器打开 <http://127.0.0.1:3000/api/health>，应返回 `{"ok":true,...}`。

**② 改 `miniprogram/config.js` 指到本地**

```js
module.exports = {
  backend: 'http',
  httpBase: 'http://127.0.0.1:3000',   // 注意：不要带结尾斜杠
  devOpenid: 'boss'                     // 测试身份，随便起名；上线前必须清空
}
```

**③ 开发者工具**

1. 导入 `techan-shop` 目录。AppID 有就填，没有选"测试号"（测试号不能发布，测试够用）。
2. **右上角「详情 → 本地设置」→ 勾上「不校验合法域名、web-view、TLS 版本以及 HTTPS 证书」**。不勾这一项，`http://127.0.0.1` 会被拦。
3. 点「编译」。
4. 首页（目录）如果提示未初始化 → 点「初始化店铺数据」。只建店铺设置（不写示例商品），并把**当前身份设为卖家**；之后在「卖家工具 → 商品」里加东西。
5. 「我的」页底部应该出现一行虚线框：`本地测试身份：boss`。看到它就说明登录链路通了。

### 路线 B：用微信云开发（想顺便验一下云端能不能跑）

`config.js` 改成：

```js
backend: 'cloud',
envId: ''            // 只有一个环境就留空
```

然后在开发者工具点「云开发」创建免费环境 → 右键 `cloudfunctions/shopapi` → **上传并部署（云端安装依赖）** → 编译 → 首页点「初始化店铺数据」。

> 云开发模式没法伪造身份，测"两个角色"必须用两个微信号（或一个手机一个模拟器）。所以测流程还是 A 路线更省事。

### 路线 C：真机（今天也能，需同一 WiFi）

`config.js` 里把 `httpBase` 换成电脑的局域网地址。你这台机器当前是：

```js
httpBase: 'http://172.20.10.2:3000'
```

（注意 `172.20.10.x` 是 iPhone 热点的网段——手机要连同一个热点。换网络后重新用 `ipconfig getifaddr en0` 查一次。）

然后开发者工具点「预览」→ 手机扫码 → **打开后点右上角 `...` → 打开调试**，小程序会重启。这步不能省，否则微信会校验域名白名单，直接报 `url not in domain list`。

Mac 首次启动服务器可能弹"允许接受传入网络连接"，点允许。

**开着 Clash / 梯子要不要关？** 分两种情况：

- **本机访问 `127.0.0.1`（网页版、开发者工具模拟器）**：一般**不用关**。Clash 默认对回环地址直连。如果浏览器能开 `/api/health` 但小程序一直转圈，再关掉试。
- **真机访问局域网 IP（`172.20.10.x`）**：建议把 Clash 的 **TUN 模式 / 增强模式 / 虚拟网卡关掉**（普通系统代理模式没事）。TUN 会接管整台电脑的路由，手机连进来的请求经常被它截走，症状就是"浏览器能开、手机死活连不上"。
- 手机自己如果挂着代理/VPN，也要先关，否则它根本不会直连你的电脑。
- quick 判断法：手机浏览器直接开 `http://172.20.10.2:3000/api/health`，能返回 JSON 就说明网络通，剩下就是小程序配置问题；打不开就是代理/防火墙在拦。

## 1. 怎么在一个人手机上测"两个身份"

这是整个测试里最容易卡住的地方，说透一点。

后端只认 `openid`。本地测试时，`config.js` 里的 `devOpenid` 就是"我是谁"：

| devOpenid | 相当于 |
| --- | --- |
| `boss` | 你（卖家，能看到卖家工具） |
| `kehu1` | 同事小王 |
| `kehu2` | 同事小李 |

**切换方法**：改 `devOpenid` → 保存 → 回开发者工具点「编译」。约 2 秒，页面刷新成另一个人。

三个坑，都替你处理了：

- **登录态缓存**：以前改完 `devOpenid` 还在用上一个人的 token，看起来像"切不过去"。现在 token 跟身份绑定，身份一变自动作废重登。
- **怎么确认切成功**：「我的」页那行虚线框会显示当前身份；卖家身份会多出「卖家后台」卡片，买家身份看不到。
- **清单会带过去**：购物清单存在本机 storage，跟身份无关。切身份前想清干净，开发者工具点「清缓存 → 清除数据缓存」。

> 云开发模式没有这个开关，`devOpenid` 留空即可（留空就正常走 `wx.login`）。

## 3. 测试清单（照着点，15 分钟）

下面用的是**当前界面上的字**（已按工具类目改过一轮），按这个找按钮就行。

### 卖家身份（`devOpenid: 'boss'`）

1. 首页（目录）→ 点「初始化店铺数据」→ 店铺建好（首页空着）→ 「卖家工具 → 商品」加 1 条再往下测
2. 「我的」→ 看到「卖家后台」卡片 → 点「进入卖家工具」
3. 卖家工具 → **店铺设置**：改店铺名、手机号、公告 → 点「保存设置」
4. 卖家工具 → **品类**：点某个条目「编辑」→ 改参考价、传一张图 → 保存 → 回首页刷新能看到新价和图
5. 卖家工具 → 品类 → 「＋ 新增品类」→ 新建一个 → 出现在首页
6. 新建的品类把「在售展示」开关关掉 → 首页看不到它

### 买家身份（`devOpenid: 'kehu1'`）

7. 首页切分类 → 点进详情 → 选数量 → 加进清单 → 底部出现「N 件待提交 / 去登记」
8. 点「去登记」→ 选「快递寄给你」→ **不填地址**直接「提交登记」→ 应提示"请填写收货地址"
9. 改选「自取」→ 地址栏消失 → 提交成功
10. 再试一次快递 + 点「从微信收货地址一键填入」（模拟器里通常拉不到，真机能拉）
11. 提交成功 → 自动跳到「登记」tab → 状态「待确认」
12. 「我的」→ **看不到**卖家后台卡片（权限隔离 OK）

### 回到卖家（`devOpenid: 'boss'`）

13. 卖家工具 → 登记单 → 看到刚才那单：**点电话能拨号、点微信能复制**、地址、备注都在
14. 点「报价运费」填 12 → 状态变「已报运费」
15. 切回买家 → 「登记」里能看到运费 12、合计金额变了
16. 卖家点「已收款」→「已发出」→「完成」，买家侧状态跟着变
17. 买家在「待确认」时点「取消登记」→ 卖家侧显示「已取消」
18. 买家在「已收款」之后再点取消 → 应被拒绝并提示直接微信联系

### 边界（这几条最容易被忽略，但最影响真实体验）

19. **把服务器停掉**（Ctrl+C）→ 首页应给出可读的错误提示，而不是白屏或一直转圈
20. 卖家把某个品类关掉「在售展示」→ 买家清单里还有它 → 提交 → 应提示"已经下架/不可用"
21. 手机号故意填 10 位 → 提交被拦
22. 断网后重连 → 再操作一次，看是否自动恢复（token 过期会自动重登）

## 4. 体验版：给 2~3 个同事真用一下

最接近真实，而且**不需要审核、不需要发布**。

1. 开发者工具「上传」→ 版本号填 `1.0.0`
2. 小程序后台 → 管理 → 版本管理 → 开发版本 → 「选为体验版」
3. 管理 → 成员管理 → 体验成员 → 加同事微信号
4. 把体验版二维码发给他们，扫码即用
5. 他们也要"打开调试"才能绕过域名校验——除非你已经配好 HTTPS 域名

这一步能测出模拟器测不出的东西：图片加载快慢、复制微信号顺不顺手、老人看不看得清字号。

## 5. 正式版：硬性门槛（等域名和备案）

| 要求 | 说明 |
| --- | --- |
| HTTPS | 443 端口 + 有效证书（Let's Encrypt 免费，但要配 fullchain） |
| 域名已 ICP 备案 | 微信配置域名时会校验；国内服务器必须备案 |
| request 合法域名 | 小程序后台 → 开发管理 → 服务器域名，填 `https://api.你的域名.com` |
| `DEV_MODE=0` | 否则任何人都能伪造身份登录，等于后台裸奔 |
| 清空 `devOpenid` | 否则前端会一直用假身份登录，直接 401 |

> `<image>` 加载图片不校验域名白名单，但证书必须有效。所以图片走"同域返回地址"，只需要配 `request` 一个域名。

## 6. 常见报错对照

| 报错 / 现象 | 原因 | 解决 |
| --- | --- | --- |
| `request:fail url not in domain list` | 没勾"不校验合法域名"，或没开调试 | 开发者工具勾上；真机点 `...` → 打开调试 |
| `网络不通：request:fail` | 服务器没起 / 端口不对 / 地址写成 127.0.0.1（真机上） | 先浏览器开 `/api/health` 验；真机用局域网 IP |
| 浏览器能开、小程序一直转圈 | Clash/代理在接管请求 | 关 TUN/增强模式试；或临时退出 Clash |
| 一直转圈没反应 | 服务器终端被 Ctrl+C 了 | 重起 `node index.js` |
| `登录已过期` 反复出现 | 服务器每次重启 `TOKEN_SECRET` 都变 | 在 `server/.env` 里固定一个长随机串 |
| 「我的」没有卖家后台 | 当前 openid 不在 `settings.adminOpenids` | 服务器版：删掉 `server/data/db.json` 重新初始化（会把当前身份设为卖家）；云开发：控制台改 `settings.adminOpenids` |
| 图片 404 | `public/uploads` 没写权限 | `chmod -R 755 server/public/uploads` |
| 改了 `devOpenid` 但还显示旧身份 | 旧 token 缓存 | 已修；若仍出现，开发者工具「清缓存 → 清除数据缓存」 |
| `云函数未部署` | 忘了上传（云开发模式） | 右键 `shopapi` → 上传并部署 |

## 7. 测出问题怎么告诉我

把这三样发我，我能直接定位，不用来回问：

1. **哪个页面、点了什么**（例：确认下单页，选了快递没填地址，点提交）
2. **屏幕上出现的原文**（截图也行，报错文案比描述更有用）
3. **服务器终端最后几行**（本地跑的时候日志里有 `[api] xxx ...`）

技术细节不用整理。你只要说"点保存没反应"就够了。

## 8. 测试数据别带上线

- **服务器版**：停服务 → 删 `server/data/db.json` → 重起（重新初始化会清空所有登记单）。图片删 `server/public/uploads/*`。
- **云开发版**：控制台里手动删测试登记单，品类改成真实内容。
- 上线前检查：`config.js` 的 `devOpenid` 是否已清空、`.env` 的 `DEV_MODE` 是否已关。
