# 二、申请流程与主体选择（最影响你的一步）

## 先看一个关键结论

微信把「谁在运营」和「能做什么」绑在一起。对你的项目来说，唯一真正的分岔口是：

- **个人主体**：0 元、只要身份证、最快，但**不能开通微信支付**，且**开放类目里没有"卖食品"**（食品类目都要《食品经营许可证》，而个人没营业执照办不了这个证）。
- **个体工商户**：办个执照（多地可全程网办、免费），认证 30 元，能开微信支付，类目能选「生鲜/初级食用农产品」这类只需要营业执照的。

你这个流程**不需要在线支付**（线下确认邮费、微信转账），所以个人主体技术上跑得通，只是类目要"绕"；想长期正经做，个体户更省心。

> 我的建议：**先用个人主体把小程序跑起来、在同事群里试水**；如果一个月后还有单，再补个体户执照 + 类目 + 微信支付。缺点是主体变更不能直接"升级"，要把小程序迁移到新主体（有公证流程，比较烦），所以如果你已经确定要长期卖，就直接用个体户注册，一步到位。

## 两条路对比

| | 个人主体 | 个体工商户（推荐长期） |
| --- | --- | --- |
| 需要材料 | 身份证、本人实名微信、手机号、未注册过公众平台的邮箱 | 同上 + 营业执照 |
| 办理成本 | 0 元（微信认证 30 元/次，建议做） | 执照多地免费/几十元；微信认证 30 元/次（企业是 300 元/次） |
| 微信支付 | ❌ 不能开通 | ✅ 可开通 |
| 可选类目 | 工具、生活服务等，**不含食品销售** | 「商家自营 - 生鲜/初级食用农产品」只需营业执照；「食品饮料 - 地方特产」需《食品经营许可证》或《食品生产许可证》或《仅销售预包装食品备案》 |
| 一个身份证能注册几个 | 5 个 | 5 个 |
| 审核风险 | 有商品列表 + 下单，容易被判"类目不符" | 类目对得上，最稳 |

### 类目怎么选（这块最容易被打回）

- 卖**鲜货 / 未加工的农产品**（柿子、板栗、鲜笋、鸡蛋）：类目 **商家自营 → 生鲜 / 初级食用农产品**，资质只要营业执照。✅ 最省事
- 卖**加工过的食品**（蜂蜜、粉条、辣酱、腊肉、糕点）：严格来说属于食品销售，需要 **《食品经营许可证》**（或《食品生产许可证》，或"仅销售预包装食品备案"）。办个体户执照后，到当地市场监管所办"食品经营许可（仅销售预包装食品）"通常是免费的，跑一趟即可。
- **不要**为了绕资质把蜂蜜写成"农产品"——被投诉或抽查是要下架的，而且你在同事圈子里卖，口碑比类目重要。

### 如果坚持用个人主体，类目怎么写

只能选个人开放的类目，常见做法是选 **工具 → 信息查询**（或 生活服务相关），并把小程序定位描述为"**家乡特产信息展示与预订登记**"，明确不做在线交易、不收款。
- 通过率：这类"展示 + 留联系方式"的小程序一般能过，但你页面里有价格、购物清单、下单按钮，审核员仍可能判定为电商而驳回。
- 应对：第一次提审如果被拒，按驳回意见改——把"下单"改成"预订登记/询价"，把"购物车"改成"想要的清单"，不要出现"支付/结算/购买"字样。
- 风险自担：类目与内容不符被举报，可能被限制功能。别大规模推广，就在同事/朋友群用，问题不大。

## 完整步骤（照着做，1~3 周）

### 第 1 步 注册账号（30 分钟）
1. 准备一个**从未注册过公众号/开放平台**的邮箱（QQ 邮箱、163 都行）。一个邮箱只能注册一个小程序。
2. 打开 <https://mp.weixin.qq.com> → 右上角「立即注册」→ 选「小程序」。
3. 填邮箱、密码，去邮箱点激活链接。
4. 选主体类型 → 填信息：
   - 个人：姓名、身份证号、手机号，管理员微信扫码做人脸核身。
   - 个体户：主体类型选「企业」→「个体工商户」，名称必须和执照**一字不差**（含"(个体工商户)"全角括号）。
5. 完成后能在后台看到 **AppID**（开发管理 → 开发设置），等下要用。

### 第 2 步 微信认证（1~3 个工作日，30 元）
后台首页「微信认证」→ 去认证 → 填资料 → 支付 → 等审核电话（只问两件事：是否本人提交、复述主体名称），保持手机畅通。
- 认证后才有"被搜索""被分享"能力。不做认证基本等于没人能找到你的小程序，**建议做**。
- 到期要年审，别忘了。

### 第 3 步 填小程序信息
设置 → 基本信息：
- **名称**：全网唯一、一年只能改 2 次（改名要重新认证、再交钱，一次想好）。个人主体不能带"商城、商贸、公司、集团"等字。
- **头像**、**简介**（简介会出现在搜索结果里，写清楚"老家特产、熟人小单、微信确认后转账"）。
- **服务类目**：按上面「类目怎么选」填。

### 第 4 步 ICP 备案（必须，1~20 天，多数 3~7 天）
2023 年 9 月起，小程序**不备案不能上线**。
- 入口：后台首页「去备案」/ 设置 → 小程序备案。
- 个人主体只需身份证 + 人脸核身 + 通讯地址（要能联系到你）。
- ⚠️ 平台初审通过后，工信部（12381）会给你发短信，**必须在 24 小时内**去 beian.miit.gov.cn 核验，超时要重来。设个闹钟。
- 这个可以和第 5、6 步并行，不用等。

### 第 5 步 开通云开发（5 分钟，0 元）
1. 下载「微信开发者工具」（稳定版即可），用管理员微信扫码登录。
2. 导入本项目（选 `techan-shop` 目录），AppID 填你刚拿到的。
3. 点工具栏左上角「云开发」→ 开通 → 创建环境（名字随便，如 `techan`）→ 选**免费**套餐。
4. 记下环境 ID。如果你只有一个环境，本项目会自动用它（`miniprogram/config.js` 里 `envId` 留空即可）。

### 第 6 步 部署后端 + 初始化数据
1. 在开发者工具左侧文件树里，右键 `cloudfunctions/shopapi` → **上传并部署：云端安装依赖**。等它跑完（约 1 分钟）。
2. 编译小程序，点首页的「初始化店铺数据」按钮（或者 我的 → 初始化店铺数据）。
   - 它会：创建 5 个集合 → 写入店铺设置（**把你当前微信设为管理员**）→ **只建店铺设置，不写示例商品**（商品和分类你自己加）。
3. 回到「我的」页，出现「进入管理后台」入口 = 你是管理员，成功了。

### 第 7 步 换成你自己的内容
管理后台 → 店铺设置：改店铺名、手机号、公告、运费说明 → 保存。
管理后台 → 商品：新增商品 / 传图 / 上下架。

### 第 8 步 提审 & 发布
1. 开发者工具右上角「上传」→ 填版本号（如 1.0.0）。
2. 后台「版本管理」→ 提交审核（选类目、写版本描述、如实填用户隐私说明）。
   - 隐私说明照着填：收集**手机号、收货地址**，用于联系用户确认订单和发货；不对外提供。
3. 审核 1~3 个工作日。**审核通过不会自动上线**，要回后台手动点「发布」。
4. 发布后：把小程序卡片发到同事群 / 生成小程序码贴在工位。

### 第 9 步（别忘了）转付费环境
上线后 **15 天内**，去云开发控制台把免费环境转成基础套餐（19.9 元/月），否则环境到期数据读写失败。

## 常见卡点速查

| 现象 | 原因 / 解决 |
| --- | --- |
| 提审被拒："类目与内容不符" | 改类目，或按驳回意见弱化"购买/支付"字样，描述改成"展示与预订登记" |
| 提审被拒："涉及食品销售需资质" | 换个体户主体 + 相应类目，或去掉食品类商品，只留初级农产品 |
| 「管理后台」入口不见了 | 你的 openid 变了（换了微信/换了环境）。云开发控制台 → 数据库 → settings → 文档 `shop` → `adminOpenids` 里加上新的 openid。在「我的」页最底部连点那行版本号可以复制当前 openid |
| 云函数报"未部署" | 右键 `shopapi` → 上传并部署（云端安装依赖） |
| 图片不显示 | 云存储权限：控制台 → 存储 → 权限设置，选"所有用户可读，仅创建者可写" |
| 备案后还是搜不到 | 审核通过要手动「发布」；发布后有灰度期，等 1~2 天 |

## 二、提审时三处关键话术

**① 服务类目**：选个人开放的类目，优先 `工具 → 信息查询`（或 `工具 → 效率`）。
不要选任何带"商家自营 / 电商平台 / 食品"的类目——选了就等于自报需要资质。

**② 小程序简介**（会出现在搜索结果里）：

> 家乡特产信息展示工具。提供特产图文、产地与参考价查询，以及需求登记，方便熟人间沟通；小程序内不提供在线交易与支付。

**③ 提审时的「功能页面说明 / 备注」**（审核员主要看这里，认真写）：

> 本小程序为信息展示与需求登记工具，非电商平台：
> 1. 仅展示家乡特产的图文介绍、产地信息和参考价，不提供在线下单交易；
> 2. 页面中的「登记」仅收集用户想要的数量与联系方式，提交后由运营者通过微信/电话线下沟通；
> 3. 小程序内无任何支付功能、无购物车结算、无订单履约流程，不涉及资金往来；
> 4. 商品由运营者自采自销的初级农产品，不涉及第三方商家入驻。

**④ 用户隐私保护指引**里要如实勾选：`手机号`、`微信昵称/头像`（如用到）、`收货地址`（因为地址一键填入）。不勾会被打回。

## 三、通过率与风险，说清楚

- 这套改法能显著降低"类目不符/需资质"的驳回概率，但**不等于合规豁免**。审核是人工判断，看到价格 + 数量 + 地址 + 联系方式，仍可能认为构成销售。
- 若被驳回，按驳回意见改，别硬刚：删掉"合计"金额、把参考价改成"面议/时价"、把地址改成"备注里说明"——一步一步退，直到过。
- 上线后仍可能被投诉（同行或不满意的客户），一旦被要求补资质，还是要走个体户那条路。**别把宝押在"审核没看见"上。**
- 真心想长期做，最省心的顺序是：先用这套工具版跑起来验证有没有人买 → 有量了补个体户执照 → 再加「初级食用农产品」类目 → 需要的话开微信支付。主体变更要迁移小程序（有公证流程），所以别拖太久。
