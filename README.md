# 老家特产小铺 · 微信小程序

给熟人卖老家特产用的轻量小程序：**展示 + 下单登记 + 卖家后台**。
不接在线支付 —— 买家登记后你拿到电话，确认邮费与总额，微信转账收款。

后端有**两套，任选一套**，业务逻辑完全一致，前端只改一行配置：

| 后端 | 位置 | 适用 |
| --- | --- | --- |
| 微信云开发（默认） | `cloudfunctions/shopapi/` | 不用买服务器，微信托管，~19.9 元/月 |
| 自建服务器（零依赖 Node） | `server/` | 有现成服务器/域名，数据在自己手里 |

## 先跑起来（本地测试模式，2 分钟）

`miniprogram/config.js` 现在预设成**本机测试**：`backend: 'http'` + `httpBase: 'http://127.0.0.1:3000'` + `devOpenid: 'boss'`。

**最快验证：双击根目录的 `启动服务器.command`** → 终端里起服务、浏览器自动打开 <http://127.0.0.1:3000/app.html>，这就是内置网页版，不用微信也能把流程点完。

测真小程序则两步：

1. 终端：`cd server && DEV_MODE=1 node index.js`（这个窗口别关）
2. 开发者工具「导入项目」选这个目录 → 编译 → 首页点「初始化店铺数据」

「我的」页底部出现一行虚线框 `本地测试身份：boss`，就通了。**不需要 AppID、不需要云环境、不需要服务器。**

**不开微信也想看？** 浏览器直接打开 <http://127.0.0.1:3000/app.html> —— 内置网页版，界面同款，顶栏可以一键切换「我是谁」，整条流程都能点完。见 `docs/04-测试指南.md` 的「路线 0」。

改 `devOpenid` 为 `kehu1` 重新编译，就变成买家身份 —— 一台电脑测两个角色。完整测试清单见 `docs/04-测试指南.md`。

### 换成云开发模式

1. **注册小程序**拿 AppID（详见 `docs/02-申请流程.md`）
2. 微信开发者工具「导入项目」→ 填 AppID → 点「云开发」创建环境（免费）
3. `config.js` 改 `backend: 'cloud'`、`devOpenid: ''`
4. 右键 `cloudfunctions/shopapi` → **上传并部署（云端安装依赖）** → 编译 → 首页点「初始化店铺数据」

> 还没注册小程序？AppID 可以先选「测试号」，但**测试号不能发布上线**，也不能用云开发。先测界面就用上面的本机模式。

**自建服务器正式部署**：`cd server && cp .env.example .env`（填 APPID/APPSECRET/TOKEN_SECRET）→ `node index.js` → `config.js` 改 `httpBase` 为正式域名。详细见 `server/README.md`。

### 两套后端都能先跑自动化测试

```bash

cd server && DEV_MODE=1 node index.js &   # 服务器版（DEV_MODE 只用于测试）

```

测试怎么分层、怎么在真机上测，见 **`docs/04-测试指南.md`**。

## 两种后端怎么切换

改 `miniprogram/config.js` 一个字段：

```js
// 方案一：云开发
module.exports = { backend: 'cloud', envId: '', cloudFunction: 'shopapi' }

// 方案二：自建服务器
module.exports = {
  backend: 'http',
  httpBase: 'https://api.example.com',   // 本地测试可 http://192.168.x.x:3000
  devOpenid: ''                          // 本地联调才填，线上必须空
}
```

前端页面代码一行都不用改 —— `utils/api.js` 里把两套调用封装成了同一个 `call(action, data)`。

## 订单流程

```
对方提交登记 (pending 待确认)
   ↓  你在卖家工具里填运费 → 自动变「已报运费」(quoted)
对方微信转账给你
   ↓  你点「已收款」(paid)
你寄出
   ↓  你点「已发出」(shipped) → 对方拿到后你点「完成」(done)
异常：你在后台或对方在「登记」页里「取消登记」(cancelled)
```

界面上的字按「工具」类目做过一轮替换（下单→登记、订单→登记单、商品→品类、待付款→已报运费、已付款→已收款、已发货→已发出），代码里的 `status` 值没变，仍是 `pending / quoted / paid / shipped / done / cancelled`。

买家侧看到的状态和你在后台看到的一致；你写的「留言」会显示在买家的订单卡片上（比如"明天下午发出"）。

## 买家下单要填什么

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 姓名 | ✅ | 收货人姓名 |
| 手机号 | ✅ | 11 位校验，后台点一下直接拨号 |
| 收货地址 | ✅ | 固定走快递；可以点「从微信收货地址一键填入」 |
| 备注 | 否 | 什么时候要、要多少、忌口等 |

地址和联系方式会存在订单里、也记在本地：同一个人第二次下单时自动带出上次填的，不用重填。前端校验只是体验，**服务端 `createOrder` 会再校验一遍**（姓名、手机号格式、地址长度），绕过前端也塞不进脏数据。

> 「一键填入」用的是 `wx.chooseAddress`，需要在 mp 后台「设置 → 服务内容声明 → 用户隐私保护指引」里勾上「收货地址」。没勾也不会报错挡路，只是会提示手动填。

## 数据库集合

| 集合 | 作用 | 权限建议 |
| --- | --- | --- |
| `settings` | 店铺设置，文档 `_id = shop`，含 `adminOpenids` 管理员白名单 | 所有用户不可读写 |
| `categories` | 分类 | 同上 |
| `products` | 商品 | 同上 |
| `orders` | 订单 | 同上 |
| `users` | 用户默认联系方式（`_id` = openid） | 同上 |

**权限全部设成「所有用户不可读写」**，前端一律通过云函数访问。这样没人能绕过你的校验去读别人的订单、改商品价格。

> 唯一的例外是**云存储**：图片要能显示，权限用默认的「所有用户可读，仅创建者可写」。

## 云函数接口一览

| action | 谁能调 | 说明 |
| --- | --- | --- |
| `bootstrap` | 任何人（只在没有 settings 时生效） | 初始化：建店铺设置、把你设为管理员（不写示例商品） |
| `me` | 所有人 | 返回 openid、是否管理员、店铺公开信息、我的联系方式 |
| `getHome` | 所有人 | 分类 + 在售商品 + 店铺信息 |
| `getProducts` | 所有人 | 按 id 批量取商品（结算页核价用） |
| `createOrder` | 所有人 | 下单（**金额按数据库价格重算，不信前端**） |
| `myOrders` / `cancelOrder` | 所有人 | 只看/只改自己的订单 |
| `saveContact` | 所有人 | 保存默认联系方式 |
| `admin*` | 仅 `adminOpenids` 里的人 | 订单管理、商品增删改、店铺设置 |

## 常见问题

**提审被拒「类目与内容不符 / 涉及食品销售」？**
界面文案已经按"工具"路线改过一轮（下单→登记、订单→登记单、商品→条目），改文案后跑 `node scripts/check-copy.js` 自查。提审备注怎么写、类目怎么选，见 `docs/02-申请流程.md` 末尾的附录。

**「卖家工具」入口没了？**
换微信登录后 openid 变了。去云开发控制台 → 数据库 → `settings` → 文档 `shop` → `adminOpenids`，把你新的 openid 加进数组。新的 openid 可以在「我的」页连点最底部那行小字复制。

**首页显示"加载失败：云函数未部署"？**
右键 `cloudfunctions/shopapi` → 上传并部署：云端安装依赖。

**商品加了但首页不显示？**
检查 `onSale` 是不是 `false`、`catId` 是否对得上分类的 `_id`。下架状态的商品在后台仍可见。

**上线后数据突然读不到了？**
云开发免费环境在小程序发布后第 15 天到期，去控制台转成基础套餐（19.9 元/月）。

**想要"有人下单就通知我"？**
需要接「订阅消息」：买家下单时弹一次授权，之后微信服务通知能推给你。这需要申请消息模板，属于下一步扩展，当前版本是你主动打开后台看。

**想接在线支付？**
要个体户/企业主体 + 微信支付商户号，且需要相应类目资质。当前设计刻意绕开了支付（线下转账），省了资质、费率、退款纠纷。
